      How we pick the shortlist

      1. Exclude films connected to anyone’s avoids. Avoiding a specific film only excludes that film.
      2. Require at least one match to every guest’s likes. A liked film can match by genre, cast or director.
      3. Rank by each guest’s taste match. The lowest match counts for 60%, and the group average counts for 40%.
      4. If there is no full match, the host can start a compromise ballot. It still respects every Avoid and ranks films by how many guests match, then taste score.
      5. Everyone gets one vote. If votes tie, the film higher on the shortlist wins.
